Privacy Policy

Last updated: September 13, 2026

Contact: isaactesfalidet6@gmail.com

InternPilot AI helps students discover, rank, track, and prepare for internship applications. This policy explains what information we collect, how we use it, and the choices you have.

Information You Provide

You may provide account information, profile details, education and work authorization preferences, resumes, application records, contacts, referrals, interview notes, coding prep logs, saved answers, and related job-search content.

Optional Connected Services

If enabled, Gmail sync uses read-only access to help classify job-related emails. It does not send, delete, or modify emails. If you add an OpenAI API key, InternPilot uses it only for AI features you request. You can disconnect optional services in Settings.

How We Use Information

We use your information to authenticate you, sync your account, rank job listings to your profile, track applications, generate requested assistance, and improve the reliability and security of the service. We do not sell your personal information or use it for advertising.

Where Data Lives

Cloud data is stored in Supabase and protected by row-level security so each account can access only its own rows. The web app is hosted on Vercel. Desktop builds may also keep a local copy on your device.

Sharing

We share information only with service providers needed to operate InternPilot, such as Supabase, Vercel, Resend, and optional AI or connected-service providers when you use those features, or when required by law.

Your Choices

  • Export your data from Settings.
  • Delete app data from Settings.
  • Request account or data deletion by emailing us.
  • Remove optional API keys or connected accounts at any time.

Security

InternPilot uses HTTPS in transit and account-scoped database policies. No system is perfectly secure, so please report suspected security issues by email.

Changes

We may update this policy as InternPilot changes. Material updates will be reflected by a new last-updated date.
